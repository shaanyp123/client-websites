# client-websites

Bespoke marketing sites for Tuulip and Vocarra clients. One standalone
Next.js + Tailwind app per client under `clients/<slug>/`, each deployed as
its own Vercel project.

**Start with [`CLAUDE.md`](./CLAUDE.md)** — it holds the full workflow,
guardrails, and new-client checklist. Templates are in `templates/`,
operational runbooks in `runbooks/`, and `clients/_reference/` shows the
required config → CTA → JSON-LD wiring. The original approved spec is
[`SPEC.md`](./SPEC.md).
